Pakiet instalacyjny dla Debiana 13 (i pochodnych) – instalacja w `/opt/szukaj_cpu`, konfiguracja w `~/.szukaj_cpu/szukaj_cpu.toml`, usługa `szukaj_cpu@<użytkownik>`.

```bash
sudo apt install ./szukaj-cpu_1.0.1_all.deb
szukaj-cpu --init && nano ~/.szukaj_cpu/szukaj_cpu.toml
szukaj-cpu --test
sudo systemctl enable --now szukaj_cpu@$USER
```

Przejście ze starej instalacji (`~/szukaj_cpu`): najpierw `bash uninstall.sh` z repozytorium – przeniesie konfigurację, modele i statyczny ffmpeg do `~/.szukaj_cpu`.

### Zmiany w 1.0.1
- co 5 minut w logu: pamięć programu, procesów ffmpeg i bufora klipów w `/dev/shm`
- czyste zatrzymanie usługi (wcześniej SIGABRT od wątków OpenVINO przy wyjściu)
- usługa: ustawienia alokatora glibc ograniczające wzrost pamięci przy długiej pracy
- `setup-ntfy.sh`: repozytorium `archive.ntfy.sh` (stare `archive.heckel.io` wyłączone), awaryjnie pakiet z Debiana
- `uninstall.sh`: czytelniejszy podgląd `--dry-run` i wskazówki dalszych kroków

### 1.0.0
- pakiet .deb, instalacja w `/opt`, konfiguracja w `~/.szukaj_cpu`
- analiza bezpośrednio w OpenVINO (bez PyTorch w czasie pracy), narzędzia eksportu modelu osobno (`szukaj-cpu-export-tools`)
- lokalny serwer ntfy z przechowywaniem wiadomości i zdjęć (`ntfy/setup-ntfy.sh`)

Pakiet wymaga dostępu do internetu przy instalacji (pobiera OpenVINO i OpenCV do `/opt/szukaj_cpu/venv`).
