## szukaj_cpu 1.0.3

### New
* **Web panel** `/admin/` in the gallery server: choose a camera, draw the detection zone
  (polygon) and the crop rectangle on a live snapshot, save to `szukaj_cpu.toml`
  (with `.bak` copy) – applied immediately, no restart needed.
* **Restart service** button (works under systemd).
* **Login**: `http_user` / `http_password` in `[gallery]` – HTTP Basic auth for the whole site.
  Without them the panel is disabled and the gallery works as before.
* **`crop = [x1, y1, x2, y2]`** per camera – only this part of the frame is analysed
  (better detection of distant people, less work).

### Upgrade
```bash
sudo apt install ./szukaj-cpu_1.0.3_all.deb
# add to [gallery] in ~/.szukaj_cpu/szukaj_cpu.toml:  http_user = "…"  http_password = "…"
sudo systemctl restart szukaj_cpu@$USER
```
